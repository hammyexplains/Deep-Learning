---

# What is a Neuron?

A Neuron is the smallest building block of a Neural Network.

The idea comes from the human brain.

Our brain contains billions of neurons.

Each neuron receives information, processes it, and passes it to other neurons.

Similarly, an Artificial Neuron:

1. Receives inputs
2. Processes them
3. Produces an output

---

# Structure of a Neuron

A neuron mainly contains:

- Inputs
- Weights
- Bias
- Activation Function
- Output

### Inputs

Inputs are the features given to the model.

Example:

Suppose we want to predict whether a student will pass or fail.

Inputs can be:

- Hours Studied
- Attendance Percentage

These values are fed into the neuron.

---

### Weights

Not every input is equally important.

For example:

- Hours Studied may be more important.
- Attendance may be less important.

Weights represent the importance of each input.

Higher weight → More influence on the prediction.

Lower weight → Less influence on the prediction.

---

### Bias

Bias helps the neuron adjust its output.

Think of bias as an additional value that allows the model to shift its decision boundary.

Without bias, the model becomes too rigid.

---

### Weighted Sum

The neuron first calculates:

\[
z = (w_1x_1 + w_2x_2 + ... + w_nx_n) + b
\]

Where:

- \(x\) = Inputs
- \(w\) = Weights
- \(b\) = Bias

This value is called the weighted sum.

---

### Activation Function

The weighted sum is then passed through an activation function.

The activation function decides:

- Whether the neuron should activate
- What output should be generated

Common activation functions:

- Sigmoid
- ReLU
- Tanh

---

### Output

The final result generated by the neuron is called the output.

This output can be passed to other neurons.

---

# What is a Neural Network?

A Neural Network is a collection of multiple neurons connected together.

Instead of a single neuron making a decision, many neurons work together to learn patterns.

---

# Layers in a Neural Network

A Neural Network consists of three types of layers:

## 1. Input Layer

Receives data from the outside world.

Example:

- Hours Studied
- Attendance

These features enter through the input layer.

---

## 2. Hidden Layers

The actual learning happens here.

Hidden layers:

- Learn patterns
- Extract relationships
- Perform calculations

A neural network can have:

- One hidden layer
- Multiple hidden layers

More hidden layers generally mean the network can learn more complex patterns.

---

## 3. Output Layer

Produces the final prediction.

Examples:

### Classification

Output:

- Pass
- Fail

### Regression

Output:

- Salary
- House Price

---
